# B8 Level 2 Assignment 1

This project contains a TypeScript practice assignment focused on core TypeScript concepts such as types, generics, unions/intersections, tuples, OOP, and async patterns.

## Included files

- [solutions.ts](./solutions.ts) — all coding solutions for the assignment
- [type-vs-interface.md](./type-vs-interface.md) — blog post on TypeScript `type` vs `interface`
- [union-and-intersection-types.md](./union-and-intersection-types.md) — blog post on union and intersection types

## Highlights

- Optional/default/rest parameters
- Readonly tuples
- Type narrowing with `typeof`
- Generic functions and `keyof` constraints
- Interface-based modeling
- Class inheritance and access modifiers
- `Promise` and async validation
